Тема: Интернет-магазин ключей игр
1. Актуальность
Цифровая дистрибуция игр вытесняет физические носители. Пользователям нужен быстрый сервис для покупки ключей с автоматической выдачей. Прототип демонстрирует все ключевые бизнес-процессы: каталог, фильтрацию, корзину, оплату и выдачу ключа.

2. Целевая аудитория
Роль	Описание
Покупатель	Геймеры 14–35 лет
Администратор	Управление каталогом и ключами

3. Функциональные возможности
Покупатель:
Просмотр каталога, фильтрация по платформе, поиск

Добавление в корзину, изменение количества

Оформление заказа (имя + email)

Оплата картой (тестовый режим)

Мгновенная выдача ключей

Администратор:
Добавление/удаление игр

Загрузка ключей (списком)

Просмотр статистики и заказов

Платёжная система:
Форма оплаты картой с валидацией

Тестовая карта: 4242 4242 4242 4242 / 12/28 / 123

Ключи выдаются только после успешной оплаты

4. Технологии
Компонент	Технологии
Frontend	HTML5, CSS3, JavaScript
Стили	CSS3 (адаптивный дизайн)

5. Ожидаемый результат
Рабочий прототип с возможностью:

Выбрать игру → добавить в корзину → оплатить (тест) → получить ключ

Демо-данные: 6 игр + ключи к ним

Запуск: открыть index.html в браузере
